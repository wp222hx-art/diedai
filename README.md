## 评选机制
1. **线上初选**：任何人可为作品打分（叙事 / 视觉 / 完成度，各 1—10 分）；登录用户按账号、匿名按设备去重；作者不能自评。
   - 排名分 = `v/(v+m)·R + m/(v+m)·C`（m=10，C=全站均分），抑制少量刷分
   - 赛道（专业团队 / 院校毕业生）前 25% 且 ≥15 人评分 → 推荐晋级路演
2. **路演**：运营录入路演综合分（≥70 通过）与评议意见
3. **双人审批**：初审核定算力面值（1 万—300 万元）→ 另一名运营复核 → 从“路演扶持池 / 院校专项池”原子扣减并发放标准 Token

## v4.1 出海与交易中心（2026-10-27）
`#/export` 由单页升级为 6 个子板块：总览 / 交易模式 / 交易流程 / 出海片单 / 发行 / 我的交易，外加交易室与上架表单。
- **8 种交易模式**：版权买断、授权许可、保底+分成（MG）、纯分账、代理发行、联合出品、改编期权、地区预售。每种模式都写明怎么运作、适合什么作品、创作方能拿到什么、要注意什么，并附「怎么选」对照表；`POST /api/export/calc` 可测算创作方到手金额（演示口径）
- **9 阶段交易流程**：询价 → 看片 → 报价（可多轮还价）→ 条款 → 签约 → 交付 → 上线 → 回款 → 完结；每一步都写明谁来做、留什么证据，按角色限制操作，每次状态变化都写入 `export_events` 留痕

- **出海片单**：作品有已上线视频才能上架，需勾选权利确认并经运营审核；片单可按地区和模式筛选，详情页能看片、查看已签约权利，机构可直接询价
- **发行**：8 步发行路径、标准交付清单、渠道矩阵（标注「候选」状态）、回款分账瀑布；交易室里可以规划发行窗口（必须在已签约地区内）
